# 📊 Mega Mart Profit Report | Power BI Dashboard

## 1. Project Overview
An interactive Power BI dashboard to analyze sales, profit, quantity, product performance, regional trends, and customer segments for better business decision-making.

## 2. Tech Stack
- Microsoft Power BI
- Power Query
- DAX
- GitHub

## 3. Data Source
- **Source:** Kaggle
- **Data:** Sales, profit, quantity, product sub-categories, regions, cities, and customer segments.

## 4. Features & Highlights

### Business Problem
Understanding product profitability, regional performance, and customer contributions is essential for improving business decisions.

### Dashboard Insights
- **KPIs:** Total Profit 286.40K, Sales 2.30M, Quantity 38K.
- **Profit by Category:** Technology is the largest profit contributor.
- **Profit by Region:** West leads in profitability.
- **Profit by Segment:** Consumer contributes the highest profit.
- **Yearly Trend:** Profit shows an upward trend from 2016 to 2019.
- **Sub-Category Analysis:** Copiers leads in profit, while Tables and Bookcases show losses.
- **City Filter:** Explore performance across different cities.

### Business Impact
Helps identify profitable products, analyze regional performance, understand customer segments, and highlight areas for profitability improvement.
